# Property Finance Manager v2.0

A comprehensive property finance management dashboard with real-time analytics and portfolio tracking.

## Features

### 📊 Dashboard
- Real-time financial health overview
- Interactive charts (income vs expenses, category breakdown)
- Property portfolio summary
- Budget performance tracking
- Recent activity feed

### 🏠 Property Management
- Portfolio value tracking
- Tenant management
- ROI calculations
- Loan and equity tracking

### 💰 Financial Tracking
- Income/expense categorization
- Budget planning and monitoring
- Cash flow analysis
- Net worth calculation

### 🎯 Key Improvements in v2.0
- **Real-time filtering** without page reloads
- **Working FAB** with smooth animations
- **Persistent filters** using localStorage
- **Export functionality** for dashboard data
- **Responsive design** for all devices
- **Performance optimizations**

## Installation

### Prerequisites
- Node.js 16+
- Modern web browser

### Setup
```bash
# Clone the repository
git clone -b version-2.0 <repository-url>

# Navigate to project
cd property-finance-manager

# Install dependencies
npm install

# Start development server
npm run dev
